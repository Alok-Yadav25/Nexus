# Research pipeline

The Python service is internal, authenticated by `X-Service-Token`. Health is public; research, embedding and source checks require the token. Java owns user permissions, jobs, retries, publication, and application data.

LangGraph stages are CLASSIFYING → PLANNING → RESEARCHING → SOURCE_EVALUATION → CLAIM_EXTRACTION → VERIFICATION → ARTICLE_GENERATION → CITATION_AUDIT → GRAPH_EXTRACTION → MEDIA_PROCESSING → VALIDATION → REVIEW_REQUIRED. The graph interrupts after every node. SQLite checkpoints with stable job thread IDs survive graph reconstruction. Redis supplies bounded advisory queue entries and event streams. Lost queue hints fall back to polling durable PostgreSQL jobs; a queue entry never grants permission or bypasses a database lease. The Java worker leases one pending job, calls one actual stage, saves the returned checkpoint to PostgreSQL, and emits an event.

The default without a Groq key is explicitly **extractive**. It proposes research questions, harvests permitted public source text, records metadata and license notes, takes bounded exact excerpts, and creates a reviewable structured draft. Optional Groq synthesis organizes those quotations into subject-specific sections. It never changes their UNVERIFIED status or establishes independent corroboration. Primary/preprint and secondary limitations are retained. Syndicated or Wikipedia pages share independence groups.

Set server-only GROQ_API_KEY locally and GROQ_ENABLED=true to enable hosted inference. GROQ_MODEL is configurable (default openai/gpt-oss-20b). Model availability and strict-schema support still require a live probe with the configured account. The official SDK uses zero automatic retries and a bounded timeout; the job layer owns retries. Schema validation, finish-state checks, known-claim-ID validation, input/output budgets, a persistent daily request cap, and Retry-After cooldown protect this stage. Failures leave source-backed extractive notes and a provider warning. The model can produce unsupported explanations despite schema validity; an authorized reviewer must explicitly accept generated text and select its cited claims before publication.

An extensible registry queries Wikidata, Wikipedia and Crossref without a finite subject whitelist. Candidate IDs, descriptions, source links and metadata states remain distinct; ambiguous labels never silently merge. Selecting a Wikidata or Wikipedia identity carries its canonical ID into the research job and sign-in return path. Registry discovery metadata does not itself support factual article claims. Programmatic Wikimedia calls are serialized and conservatively paced; NEXUS_RESEARCH_CONTACT supplies a genuine operator email/URL in the User-Agent when configured. Research harvesting remains narrower than unrestricted web search: it retrieves a permitted Wikipedia main article and up to two linked arXiv abstract pages. Failed providers are recorded as warnings; missing permitted sources fail honestly.

Claim excerpts must exist verbatim in the retrieved source text; claim text must be contained in its excerpt. Citation audit runs before validation. Instruction-like sentences are filtered, retrieved JavaScript is never run, and no source text is evaluated as tool instructions. This rule-based filter is defense in depth, not a proof of complete prompt-injection resistance.

Real-topic excerpts begin UNVERIFIED. Proposed fictional or hypothetical ontology remains visible and requires reviewer confirmation. There is no numerical confidence percentage. Graph and media extraction still return empty candidate lists; independent fact-checking, Wikidata triple extraction, Commons licensing and CLIP adapters remain unfinished. The named workflow stages are not a claim that twelve independent expert agents exist.

The scientific viewer endpoints are separate from article publication. NASA/JPL Horizons supplies actual physical reports and orbital elements, NASA PDS supplies ring radii, and PubChem supplies actual atom IDs, bonds, conformer coordinates and units. No source failure produces substitute geometry. These data are cached in PostgreSQL; stale fallback retains the original retrieval timestamp and is explicitly labeled. Educational orbital propagation is a two-body approximation, and molecular distances describe a computed conformer. Appearance, atom radii, ring opacity and viewing orientation are illustrative.

Failures retain state and retry up to three attempts with backoff. Explicit retry resumes the same workflow thread. No provider failure publishes content. Reviewers select the claims to retain, assign a rationale, confirm domain/ontology and approve. Cross-ontology verification states are rejected by Java.

Embedding uses FastEmbed / `BAAI/bge-small-en-v1.5`, an English small embedding model rather than a large local LLM. Qdrant collection dimensions are created from actual output. Network/model failures expose a 503 and do not generate dummy vectors. BGE-M3 multilingual embeddings require a separately versioned collection and are not the current baseline.
