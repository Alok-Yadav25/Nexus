# Verification states

| State | Meaning |
|---|---|
| VERIFIED | Reviewer/seed editorial assessment supports the statement through recorded evidence; not a certainty percentage |
| PARTIALLY_VERIFIED | Some aspects supported; limits must be described in rationale |
| DISPUTED | Material disagreement remains; contradictory evidence must be preserved |
| UNVERIFIED | An extracted assertion with evidence provenance but no established independent corroboration |
| OUTDATED | Previously recorded knowledge requires current revalidation |
| FICTIONAL_CANON | Assertion belongs to fictional narrative canon |
| THEORETICAL_MODEL | Assertion belongs to a hypothetical proposal or scientific model |

Ontology, verification, publication, source reachability, and index health are separate axes. A source being reachable is not factual verification. An unreachable source may reflect a temporary network problem rather than a broken publication. A human approval does not make an article fully indexed.

No confidence percentage is produced by the baseline. Research sources carry independence groups and explicit limitations. The baseline does not promote matching copies into independent verification. Review notes and per-claim rationales are required and retained.

Quality scanning flags missing evidence, orphan graph entities, stale articles, disputed claims, stale projection versions, exhausted index retries, and sources that cannot currently be retrieved. It preserves article content and history. Source checking uses the same allowlisted, pinned HTTPS fetcher as research. Unapproved hosts and robots exclusions remain UNCHECKED.
